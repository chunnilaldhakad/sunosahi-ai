# SunoSahi AI

An original, consent-first, two-party wage agreement verifier for the Gnani AI Internship Challenge. The application supports independent worker and employer statements, deterministic mismatch detection, separate revision-bound confirmations and audit receipts. Live Gnani voice services require server-side secrets; synthetic demonstrations are never presented as real model inference.

The complete project source, security checks, browser UI and serverless API integrations follow in the project commit.
